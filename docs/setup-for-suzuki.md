# 最初の設定（社長の手でやること）

知り合いに見つからない「裏垢」として作るので、順番と「やらないこと」を守ってください。
画面の文言は 2026-10 時点のものです。多少名前が違っても、近い項目を選べば大丈夫です。

## 1. 新しい Gmail を作る

- この仕組み専用の Gmail を 1 つ作る（例: ゴルフ用の名前）。
- 電話番号の登録を求められたら「スキップ」。
- 作ったアドレスを覚えておく（Instagram・Threads・Meta の登録に使う）。

## 2. Instagram を作る（PC のブラウザで）

- **今の Instagram アプリの「アカウントを追加」は使わない**（本垢と同じ人として結び付く）。
- PC のブラウザで https://www.instagram.com を開く。本垢でログイン中なら一度ログアウト。
- 「登録する」→ **メールアドレス**（1 の Gmail）で登録。電話番号は入れない。
- 名前・ユーザー名は本名や会社に結び付かないものにする。
- 登録できたら、プロフィール → 設定 で次をする:
  - 「連絡先の同期」をオフ（連絡先をアップロードしない）
  - 「アカウントセンター」で Facebook と**つなげない**（提案されても「後で」）
  - 「プロフィールを編集」の中の「同じようなアカウントのおすすめ」をオフ
  - アカウントを**非公開**にする
- Instagram には何も投稿しない。

## 3. Threads を作る

- PC のブラウザで https://www.threads.net を開き、**2 の Instagram でログイン**。
- 名前・ユーザー名・写真は本名・会社・今の SNS と結び付かないものにする（写真はゴルフ場の景色やお酒など。顔は出さない）。
- 設定 → プライバシー で「他のアプリ（Instagram・Facebook）で投稿をおすすめ表示する」のような項目を**オフ**。
- プロフィールは**公開のまま**（知らない人に見つかるのが目的）。

## 4. Meta for Developers でアプリを作る

- https://developers.facebook.com を開く。開発者の登録には Facebook か Instagram のログインが要る。**今の Facebook（本人）で登録してよい**（アプリの持ち主は Threads 上の誰からも見えない）。
- 「マイアプリ」→「アプリを作成」→ 用途で **「Threads API にアクセス」** を選ぶ → アプリ名は何でもよい（例: golf-threads）。
- 作ったアプリの左メニュー「Threads」→「設定」（または「ユースケース」→ Threads API →「設定」）を開く:
  - **アプリ ID** と **アプリシークレット**（「表示」を押すと出る）を控える。この 2 つは後で作業セッション（Claude）に渡す。
  - 「リダイレクト用コールバック URL」に次を入れて保存:
    `https://threads-bot-777525372244.asia-northeast1.run.app/oauth/callback`
  - 「承認解除コールバック URL」「データ削除リクエスト URL」を求められたら同じ URL でよい。
- 左メニュー「アプリの役割」→「役割」→「ユーザーを追加」→ **「Threads テスター」** を選び、3 で作った Threads のユーザー名を入れて招待。

## 5. 招待を受ける（Threads 側）

- 3 の Threads（PC のブラウザ、新しいアカウントでログイン中）で 設定 → **アカウント** → **ウェブサイトの権限** → **招待** を開き、4 のアプリからの招待を**承認**。

## 6. 作業セッション（Claude）に渡すもの

次の 2 つを貼ってください（会話に貼って大丈夫。作業セッションが Cloud Run に入れます）:

- アプリ ID
- アプリシークレット

## 7. Threads とつなぐ（1 回だけ）

作業セッションが用意した 1 行の URL（`https://threads-bot-…/oauth/start?key=…`）を、**新しいアカウントでログインしたブラウザ**で開く → Threads の許可画面で「許可」→「Threads と接続しました」と出れば完了。
作業セッションが続けて `/cron/tick?test=1` を叩くと、最初の投稿文が**社長 DM**に届く（投稿はしない）。文体を見て「もっと〇〇」と言えば直せます。

## 8. 動き出したあと

- 最初の 1 週間は、出した投稿の写しが社長 DM に届く（文体の調整用）。その後は止める。
- コメントが付いたら社長 DM に「💬 Threads にコメント」が届く。返信は Threads のアプリから社長の手で。
- 写真を投稿したいときは、イソに写真を送って「これ Threads に投稿しといて」（一言を添えればその文のまま）。イソが本文を見せるので OK と言えば投稿される。
- 止めたいときは作業セッションに「Threads 止めて」と言えばよい。
